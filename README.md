## 🤖 AI & LLM Systems

The work I'm proudest of right now lives at the agent layer — building the contracts, security models, and developer experience that let LLMs act on real systems.

**MCP servers**  
Built and shipped Prisma's Model Context Protocol server (HTTP transport for Cursor, VS Code, Claude Code) exposing provisioning, backups, connection strings, SQL execution, and schema introspection as tools. Designed the auth and tool-call contract so coding agents can act on customer databases without ever directly holding the credential.

**LLM features in production**  
Architected Query Insights, Prisma's first Claude-powered feature, end-to-end from Labs beta to GA. Owned the security hardening of LLM tool-call responses where model output drove user-facing recommendations against customer database data — including prompt-injection considerations and GDPR-compliant consent flows.

**Agentic developer tooling**  
Led Computable, an agentic web-app generator now used by Prisma's DevRel team: structured Claude tool use over a deployment toolchain, live iframe preview with streaming UI, one-click deploy. Developed Prisma Agent Skills giving AI coding agents version-specific Prisma 7 knowledge.

**Daily practitioner**  
Daily Claude/Cursor/Claude Code user across all my work — applying AI to the engineering practice itself, not just to features.

## 🏗️ Product Development

Where systems thinking meets visual craft — the part of full-stack that lives between design and code.

**Design systems & component architecture**  
Built component libraries from scratch: token architecture (color, spacing, typography), compound component APIs in React, polymorphic primitives, and Storybook-driven development with visual regression testing across viewports. At Prisma, I led the Looma and Eclipse design systems across marketing, docs, and product surfaces.

**Accessibility-first UI**  
WCAG 2.1 compliance as a baseline. Focus management, keyboard navigation, ARIA patterns, color contrast at scale, and screen reader testing as part of how I ship.

**Frontend observability**  
Core Web Vitals instrumented via Cloudflare Analytics Engine and PostHog, tying regressions to specific component or deploy changes. Dashboards over billions of DB operations/month with Grafana and Axiom.

**Analytics-driven UX iteration**  
Rebuilt Prisma's plan-change flows (upgrade/downgrade) based on funnel analysis — analytics directly shaping UI decisions, not just A/B tests.

## 🎨 Product development

The part of my work that lives between design and code — where systems thinking meets visual craft.

**Design systems & component architecture**  
I've designed and built component libraries from scratch: token architecture (color, spacing, typography), compound component APIs in React, polymorphic primitives, and Storybook-driven development with visual regression testing across viewports. At Prisma, I standardised the component library across marketing, docs, and product surfaces.

**Accessibility-first UI**  
WCAG 2.1 compliance is a baseline, not an afterthought. Focus management, keyboard navigation, ARIA patterns, color contrast at scale, and screen reader testing are part of how I ship.

**Frontend observability for UX**  
Core Web Vitals (LCP, CLS, INP) instrumented via Cloudflare Analytics Engine and PostHog — not just measuring performance but tying regressions to specific component or deploy changes. At Prisma, I ran dashboards over billions of DB operations/month with Grafana and Axiom.

**Motion & interaction design**  
CSS-first animations, reduced-motion respect, and interaction states that feel intentional — not bolted on. Dark mode implemented at the token level, not via class toggling hacks.

**Analytics-driven UX iteration**  
Rebuilt Prisma's plan change flows (upgrade/downgrade) based on funnel analysis — analytics directly shaping UI decisions, not just A/B tests.
